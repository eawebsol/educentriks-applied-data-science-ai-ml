# Educentriks | Applied Data Science & AI/ML

**From Learning to Real-World Application**

Welcome to the Educentriks student learning repository for the 23-day, 32-hour Applied Data Science & AI/ML programme.

## Programme structure

1. Foundations — Days 1–3
2. Traditional Machine Learning — Days 4–11
3. Deep Learning — Days 12–17
4. NLP and Generative AI — Days 18–21
5. Capstone and MLOps — Days 22–23

See [COURSE_ROADMAP.md](COURSE_ROADMAP.md) for the approved day-by-day sequence.

## Getting started

1. Read [LEARNING_GUIDELINES.md](LEARNING_GUIDELINES.md).
2. Complete the [environment setup guide](00_Setup_Guide/README.md).
3. Open the relevant day's folder and start with its `README.md`.
4. Run notebooks in the documented order.
5. Attempt exercises before seeking or reviewing solutions.

## Technology baseline

- Python 3.13.x, 64-bit
- Visual Studio Code with Python and Jupyter extensions
- Jupyter notebooks
- NumPy, pandas, Matplotlib and Seaborn
- scikit-learn
- PyTorch
- Hugging Face ecosystem and Sentence Transformers
- Streamlit
- Git and GitHub
- Google Colab as an optional cloud notebook environment

Exact package versions will be pinned after compatibility testing. Follow the course setup guide rather than independently upgrading packages.

## Standard day-folder contents

Where applicable, each day folder contains:
- `README.md` — objectives, prerequisites and navigation
- `Notes/` — conceptual notes
- `Notebooks/` — instructor demonstration and student practice
- `Exercises/` — practical tasks
- `Data/` — dataset instructions and permitted samples
- `Knowledge_Check/` — review questions
- `Homework/` — independent practice

## Data and security

Large datasets and model files should not be committed directly to GitHub. Use documented source links and download instructions. Respect dataset licences and terms.

Never commit API keys, passwords, access tokens, personal information or confidential business data.

## Student Git workflow

```bash
git clone <repository-url>
cd educentriks-applied-data-science-ai-ml
git pull
```

Complete the setup guide before running notebooks.

## Repository boundary

This is the student-facing repository. Instructor notes, completed solution notebooks, answer keys and confidential delivery guidance are maintained in a separate private instructor repository.
