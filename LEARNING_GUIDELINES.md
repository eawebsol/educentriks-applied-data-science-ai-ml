# Learning Guidelines

**Educentriks | Applied Data Science & AI/ML**

## Recommended learning cycle

1. Read the day's README before class.
2. Review the conceptual notes and note unfamiliar terms.
3. Follow the instructor demonstration notebook.
4. Run each code cell and inspect the output.
5. Modify code or parameters when prompted.
6. Complete the student practice notebook and exercises.
7. Record errors and questions for discussion.
8. Revisit the knowledge check after the session.

## Classroom learning model

The programme uses a practical learning cycle:

- 20% — concepts and intuition
- 40% — instructor-led code walkthrough
- 20% — hands-on modification
- 20% — output interpretation and business discussion

## Notebook practices

- Run cells in order unless instructed otherwise.
- Read Markdown explanations and code comments.
- Understand errors instead of repeatedly rerunning cells.
- Restart the kernel and run all cells when validating your work.
- Keep personal experiments in a separate notebook copy.

## When asking for help

Include the day, notebook filename, cell number, full error message, Python version, active environment and expected result. Remove credentials and personal or confidential information before sharing logs or screenshots.
