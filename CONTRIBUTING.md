# Contribution Guidelines

This is a managed course repository maintained by Educentriks.

## Student use

- Do not directly modify shared course materials.
- Keep personal experiments in your own working copy.
- Report suspected errors with the day, filename, cell and complete error message.
- Do not upload personal information, confidential data, API keys or large datasets.

## Maintainer practices

- Preserve the approved curriculum sequence and scope.
- Keep naming conventions consistent.
- Test notebooks from a clean kernel before merging.
- Verify relative links and dataset instructions.
- Pin package versions only after environment compatibility testing.

## Suggested commit messages

- `docs: clarify Day 01 statistical concepts`
- `notebook: add Day 04 regression demonstration`
- `fix: correct preprocessing example`
- `data: document churn dataset source`
